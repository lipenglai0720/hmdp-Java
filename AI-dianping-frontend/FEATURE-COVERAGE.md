# 前后端功能对照

| 功能 | 前端入口 | 后端能力 |
| --- | --- | --- |
| 店铺分类、搜索、附近 | 逛逛好店 | 店铺分类、名称搜索及按坐标查询；定位由用户主动触发，距离仅供参考 |
| 店铺详情、优惠、笔记 | 店铺详情页 | 店铺详情、优惠列表、店铺笔记分页 |
| 笔记和互动 | 首页、店铺详情、笔记详情及发布页 | 笔记列表、发布、点赞、评论、作者和关注 |
| 用户资料、关注与签到 | 个人中心、账户资料、作者主页 | 资料查询、关注和粉丝统计、共同关注、每日签到和连续天数 |
| 预约 | 店铺详情 → 预约到店；个人中心 → 预约管理 | 创建、查看、取消；已授权商家确认或拒绝 |
| 订单 | 个人中心 → 我的订单 | 查看自己的限时优惠订单；抢购申请异步处理 |
| 店铺管理 | 个人中心 → 商家管理 | 已授权店铺列表、店铺信息修改、普通优惠及限时优惠发布 |
| AI 创作与对话 | AI 灵感助手、AI 对话助手 | 技能列表、生成与历史；对话使用按用户隔离的会话 |

部分接口是页面内部步骤，例如上传图片、获取当前账号和查询预约详情，不需要单独的页面。验证码登录当前只在本地日志输出验证码，并未接入短信。

当前没有接入支付、核销和退款；普通优惠仅展示信息，不能通过页面购买。店铺创建及商家账号绑定需要管理员处理。账户资料暂时只能查看，评论目前支持一级评论；对话结果取决于配置的模型服务，不保证模型始终可用。
